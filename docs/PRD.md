## 1. 项目概述

### 1.1 背景

某精梳毛纺企业（多车间、多产线）原有生产管理依赖纸质单据与Excel，与金蝶K3 ERP之间存在信息断层。为打通"订单→工艺→排产→制造→质检→包装→入库"全链路，建设覆盖PC Web与PDA手持终端的制造执行系统。

### 1.2 系统定位

- **行业**：精梳毛纺（毛条→前纺→后纺→包装），含复精梳、倒筒/倒毛等特殊产线
- **集成中枢**：上游对接金蝶K3 ERP（订单/物料/组织），下游对接WMS（成品入库）、电子秤（称重）、打印机（制造卡/标签）、PDA（扫码上报）
- **终端形态**：PC Web（管理与计划人员）+ PDA手持机（现场上批/翻批/扫码）+ 一体机（包装称重工位）

### 1.3 业务总流程

```
K3 ERP订单同步 ──► 计划工艺单(配料/工序路线编制) ──► 生产任务(拆批/了批)
      │                                                    │
      │                                              生成排程(按机台/工序/日期)
      │                                                    │
      │                                            打印上机制造卡下发机台
      │                                                    │
领退料确认 ◄── K3领料 ◄── 投料记录 ◄── 上批汇报(PDA扫码) ──┤
      │                                                    │
      │                                              产量汇报(逐班)
      │                                                    │
      │        抽样登记 ──► 检验报告(公式计算) ──► 公示/质检报告
      │                                                    │
      │                                            包装任务 ──► 包装执行(逐箱称重)
      │                                                    │
      │                 筒贴/箱单/吊牌打印 ──► 装箱 ──► 组托 ──► WMS入库 ──► ERP入库
      │
      └── 现场管理(出勤/排班/能耗/费用/启停/翻批) + 设备管理(保养/点检/维保) 贯穿全程
```

### 1.4 核心术语表

| 术语 | 释义 |
|---|---|
| 上批/下批 | 批次上机开始/结束的现场汇报 |
| 翻批 | 机台品种翻改（换批），记录翻批耗时 |
| 了批/了机 | 批次/任务/缸号生产结束的封账动作 |
| 批号标识 | 色块图形（如"紫叶子""三角"），车间目视区分批次 |
| 追溯批次 | 贯穿前后工序的可追溯批号 |
| 复精梳 | 毛条复精梳产线（任务/排程独立变体，毛球为在制品载体） |
| 倒筒/倒毛 | 筒纱/毛条回加工重新包装 |
| 自络筒切疵 | 自动络筒清纱器切除疵点记录 |
| 蒸纱 | 纱线汽蒸定型（车号管理） |
| 筒贴/箱贴/吊牌 | 管纱筒标/箱外标签/丝车吊牌三类打印 |
| 组托 | 装箱后码垛打托 |
| 用毛率 | 投入毛条重量/产出纱线折标重量 |
| 回潮率 | 纱线含水率；公定回潮用于折算公定重量（公重） |
| 公重/净重/毛重/去皮重量 | 公定重量/净重/毛重/去皮后的重量体系 |
| 折算产量 | 按折标率折算的标准支数产量，用于考核 |
| 混条/针梳/粗纱/细纱/并线/倍捻/摇绞 | 毛纺工序链 |

## 3. 生产管理模块

### 3.1 K3订单查看（只读）

K3 ERP生产订单同步至MES的只读镜像，作为计划编制源头。

**列表按钮交互**：无操作按钮（纯只读镜像，[2026-09-30 与用户确认]）。引入生成计划工艺单的入口在「计划工艺单编辑页」（见3.2），引入后回写订单"引入量"字段；"引入量回刷"复选框用于查询时重算引入量，"恢复删除"用于查询已逻辑删除的订单。

- **列表**（[2026-09-30 截图核对]）：查询（生产车间下拉/订单号/批号 + 复选框"恢复删除"、"引入量回刷"；按钮 搜索/更多/重置）；17列（含复选框）：序号、订单号、下单日期、类型（后处理/生产，tag）、车间、生产线、批号、缸号、加急（红✗/绿✓图标）、删除（红✗图标）、单位、数量、引入量、任务开始日期、任务结束日期、辅助属性；分页50条/页（示例总量487,819条）；双击行/单号链接进入详情页
- 详情4个Tab：
  - **生产信息**（49字段+是否荧光，与原系统逐项对齐）：订单类型、订单号、订单日期、车间名称、生产线、批号、K3数量、K3合并投料量、计划开始日期、计划结束日期、色号、品名、纺纱支数、支数、股数、折标率、已引入数量、染色类别、物料明细、物料号、物料名、物料规格、计量单位、英文品名、中文品名、打印编号、公司色号、纺纱下达日期、客户名称、销售部门、销售员、用途、产品英文名、纺纱用精梳批号、复精梳批号、原料批号、原料样板编号(OCR不确定)、原料、客户色号、缸号、打印缸号、加工单位名称、工序名称、版本名称、条染订版色号、绞染订版色号、颜色、辅助属性、BOM版本；底部复选框：是否荧光
  - **工艺要求**：络筒工艺要求、技术/计划工艺纺纱要求、工艺及倍捻要求、成品要求、标签打印要求、包装要求、复精梳纺纱备注
  - **审批信息**：订单状态、审核人/时间、作废状态/时间
  - **其它信息**：K3各ID映射（K3订单号/ID、物料ID、车间ID、产线ID、批号ID、辅助属性ID、客户ID、明细ID、加工单位ID、货主ID、打印模板ID、计量方式ID）、MES创建/更新时间、K3数据版本时间
- "是否关闭"复选框标记引入完毕

### 3.2 计划工艺单

核心单据：按批号引入K3订单，编制配料与工序路线，审核后生成排程。

**列表**：查询（生产车间/生产批次/实纺支数/原料明细）；列：计划工艺单号、单据状态、生产车间、车间产线、生产批次、批号标识、计划产量、原料明细、产品编号/规格、实纺支数、色号、合并投料量、创建人/时间；行操作：提交、工艺单打印（含前后纺版）、撤回、生成排程、合并排程、刷新排程、打印。

**编辑页**主表：批号标识、生产批号、原料明细/规格、色号、实纺支数、投料量、合并投料量、生产订单（查找弹窗）、车间、车间产线、下单日期、预计交期、生产标识、计划产量。

7个Tab：
1. **订单明细**/工序路线：类型、工序、排序、投料/报产/上下料开关、线边仓、物料/生产单位、计划产量、排程量、产出量、车间、了批、工序标识、机型；支持增删工序、上移下移、工艺配置、选择工序标识、编制工艺单
2. **用料汇总**：原料批号、原料名称、车间用料量、配料量、投料量、单位
3. **生产信息**：产品编号/名称、打印缩写、中英文品名、产品规格、辅助属性、色号、公司色码、条染/绞纱打版色号、实际支数、复精梳批号/编号、细纱支数、单位、中英文打印、用途、客户、销售部门/销售员、是否荧光、股数/支数
4. **工序要求**：特殊工艺要求、计划/技术工艺纺纱要求、工艺及倍捻要求、成品要求、标签打印要求、包装要求、前纺/翻槽/后纺备注
5. **原料检验报告**：取样批次、每米重量、不匀率、毛粒50克、杂质、回潮、毛片、异色毛、异纤、毛粒大中小、含油、草屑50克、长度、离散
6. **生产备注**

**状态机**：编制中 → 提交 → 已审核 → 生成排程；已审核可撤回。

**编辑页操作流（分步）**：保存 / **保存并继续**（保存后自动激活「工序路线」Tab）/ **编制工艺单**（按工序chips逐道编制：从车间工艺库按「工序+机型」带出工艺项参数，支持"全部带出"一键填充，进度跟踪"已编制 x/10"）/ 提交（单据锁定）。注：无"保存并审核"按钮，审核动作在提交后由权限角色执行。

**引入K3订单**（[2026-09-30 与用户确认]）：编辑页顶部「引入K3订单」按钮或「生产订单」字段🔍 lookup → 展开订单选择面板（支持订单号/批号搜索，单选）→ 确认后订单信息自动填充主信息区（生产订单号/生产批号/原料明细/色号/车间/下单日期/投料量/计划产量），覆盖提示；引入量回写K3订单「引入量」字段（重复引入拦截）。

**列表操作语义**：
- **提交/撤回**：支持勾选多张批量提交；状态互斥（编制中→提交，已提交→撤回）
- **生成排程**：一键自动——确认后系统按工序路线自动生成排程，自动分配机台、序号与计划时间（无需逐工序配置），完成后跳转生产排程列表，新排程行高亮标注
- **合并排程**：勾选≥2张工艺单，按批号合并投料自动生成（跨车间时按车间拆分；编制中状态告警提示）
- **刷新排程**：同步生产汇报/投料实绩，重算已排产量后更新排程
- **工艺单打印**：A4版式（单头信息+工序路线+用料汇总+工艺要求+二维码）

### 3.3 生产任务

**列表**：查询（创建时间/车间/生产批号/实纺支数/原料明细）；列：任务编号、编制状态（编制中/生效）、执行状态（计划执行/工艺控制）、生产批号、车间、产线、批号标识、原料明细、产品编号/规格、实纺支数、色号、合并/计划投料量、计划产量、单位。

**列表按钮交互**（倒筒任务同模式，另加"复称标签打印"=勾选后打印复称标签；任务变更走"保存→保存并审核→提交"审批流）：
- **新增**：进入编辑页
- **提交**：勾选（仅编制中）→ 批量提交为生效；**撤回**：勾选（仅生效且无排程）→ 确认 → 回编制中
- **了批**：勾选 → 二次确认（提示"了批后批次封账，不可再汇报/投料"）→ 执行状态变"了批"
- **取消子批**：勾选子任务 → 确认 → 取消（主任务不受影响）
- **关闭**：勾选 → 确认 → 任务关闭（终态，不可恢复）
- **打印**：勾选 → 打印工艺单
- **删除**：勾选（仅编制中）→ 确认 → 逻辑删除
- 通用：批量按钮需先勾选否则提示"请先勾选"；危险操作（了批/关闭/删除/取消子批）均二次确认；操作成功后行状态实时刷新

**编辑页**主表：批号标识、生产批号（如J2609988-10）、原料明细、色号、合并投料量、预计交期、任务类型（主任务/子任务）、生产车间、生产订单号、下单日期、计划投料量/产量、车间产线、纺纱方法（进口紧密纺）、原料品种/类型、股数/支数。

6个Tab：订单明细、用料汇总、生产信息（含销售部门/**销售员**、温湿度、含油等）、工艺要求、工序路线、生产备注（复精梳变体无生产备注Tab）。

**工序路线Tab-工艺配置**：引用**技术工艺库**或**车间工艺库**——选择来源后按「工序+机型」匹配方案（方案编号/版本/工艺项数），确认后带出该工序全部工艺项参数（工艺项/工艺值/上下限/单位），支持"引用带出到当前工序"（自动推进下一道）与"全部工序批量引用"；主表工序行实时标记已配置（✓）。两库差异：技术工艺库为技术部标准（TJ.../v2026.03），车间工艺库为车间执行版（CJ.../v2026.09，参数经车间化微调）。

**变体**：
- 复精梳：同构独立菜单入口；产品为毛条（4.x编码），主表多生产备注
- 任务变更：对已生效任务的调整单，走"保存→保存并审核→提交"审批流
- **倒筒任务**（回加工，独立菜单+独立页面）：
  - 列表：查询（创建时间/生产车间/生产批号/产品编号/缸号）；按钮：新增、删除、打印工艺单、**复称标签打印**、了批、取消子批、提交、撤回、关闭；列：任务编号、缸号、批号标识（倒三角等色块）、车间、编制状态、数量、预计交期、创建/修改人与时间
  - 编辑页主信息：任务编号（PT...）、生产批号、生产订单号、批号标识*、生产车间*、下单日期、预计交期*、计划投料量/产量、车间产线、包装车间
  - Tab-订单明细（9列）：序号、缸号、产品编码、产品名称、原料明细、股数/支数、计划产量、包装量、单位
  - Tab-用料汇总（8列）：序号、复精梳批号、缸号、原料编码、原料名称、计划投料量、已投料量、单位
  - Tab-生产信息（15字段）：产品编号、产品名称、打印缩写、产品英文名、客户、缸号、整精梳批号、染色类别、产品规格、品名、员工、辅助属性、确认色、客户色号、是否荧光
  - Tab-工艺要求（3字段）：标签打印要求（文本域）、编织袋(实重)、包装要求（文本域）——无工艺项表格

## 15. 非功能需求

- 单据编号规则：计划工艺单、生产任务（PI）、排程（PSC）、工单（TPC）、上批（SR）、产量汇报（OR）、质检（QC）、包装任务（PS）、包装执行（PC）、投料（MF）、倒筒（PT）、丝车（PT）等由"自动编码"引擎按前缀+日期+流水生成
- 重量精度：0.01kg；回潮/含油百分比两位小数
- 并发：车间现场多工位同时上报，需死锁管控与权限缓存
- 审计：全部单据记录创建人/时间、修改人/时间；删除类操作独立留痕（箱子删除记录）
- 停用功能保留菜单标记（如每日排班、倒毛接收出库单已停用）
