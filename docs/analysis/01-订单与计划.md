## 流转推断
K3 ERP销售/生产订单 → 同步至MES(K3订单) → 按批号合并/引入生成计划工艺单（选生产订单、配料、编制工序路线）→ 审核/提交 → 生成排程（或合并排程）/工艺单打印 → 下发车间
