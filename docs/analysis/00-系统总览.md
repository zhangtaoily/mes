## 关键业务概念（毛纺行业）
- 上批/下批：批次上机开始/结束汇报；翻批：批次切换（品种翻改）
- 复精梳：毛条复精梳产线（独立任务/排程/汇报变体）
- 倒筒/倒毛：筒纱改卷/毛条倒毛重新包装入库
- 自络筒：自动络筒工序（切疵=清纱器切除疵点）
- 蒸纱：纱线定型汽蒸处理
- 筒贴/箱贴/吊牌：管纱筒标、箱外标签、丝车吊牌三种标签打印
- 组托：码垛打托（托盘管理）
- 用毛率：原料消耗指标（投入毛条重量/产出纱线重量）
- 回潮率：纱线含水率（公定回潮折算重量）
