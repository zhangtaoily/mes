### 1.3 排程/任务表拆分差异（结构启示，不照搬）
参考系统将生产排程拆 9 表（SCH_ARG工艺项/SCH_BATCH翻批/SCH_DEV_TYPE任务来源/SCH_MAT_USE+SUM用料/SCH_OL报工/SCH_PROC_TAG工序/SCH_TASK冗余），生产任务拆 11 表，生产工艺单拆 11 表——远细于我们（任务4表/排程4表/工艺单6表）。我们按查询负载适度冗余即可，已含核心子表；SCH_TASK"冗余字段表"思路（避免联查）值得在性能优化时参考。

### 1.4 字段级要点（自字段流提取）
- 包装纸箱：SPEC规格 / **WARE_WEIGHT标准皮重** / VOLUME体积 / **BOBBIN_COUNT标准筒数** / **VOLUME_CAL体积公式**
- 打印样式：TYPE(箱贴/筒贴/其它) / PRINT_PARAM打印参数1-3 / 图片附件 / 排序权重
- 生产工序：TYPE(前纺/后纺) / **CAL_PRO_TO_MAT生产单位转物料单位公式** / CAL_PRO_TO_NUM转计数单位公式 / STAY_PERIOD质保周期 / **EDIT_TYPE必填字段(颗数/重量/全部)**
- 生产标识：COLOR_GRADE色系等级 / ALIAS别标识名 / TYPE(生产标识/工序标识)
- 质检指标公式：QC_INDEX_ID → RESULT_QC_INDEX_ID(影响指标) + FORMULA —— 即截图所见的 $BQ(...) 派生指标机制
- 班组：TEAM/START_TIME/END_TIME；人员技能：PERSON_ID×机台
