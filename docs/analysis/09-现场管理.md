# 09 现场管理域（截图：现场*）

## 1. 车间出勤
- 功能按钮：Excel导入 / 提交 / 审核通过 / 撤回
- 列：期间（月）、车间、开工天数、车间管理人员、常日班辅助、一线员工、质检组出勤、总出勤、折算出勤
- 流程：导入→保存→提交→审核通过（可驳回/撤回）
- 折算出勤 = 按班次系数折算的出勤人日，用于产量/绩效分摊

## 2. 车间排班
- 主表：车间、班组、班次、上班时间、下班时间、起始日期、截止日期
- 双子表：
  - 排班人员：姓名、工号、机台
  - 上机机台：机台号、品种/批次
- 按钮：复制（复制上一周期排班）、生成每日排班
- 班次示例：常日班/两班倒等，排班周期化模板→生成每日明细

## 3. 每日排班（已停用）
- 由车间排班"生成每日排班"替代手工维护

## 4. 人员工时
- 列：工时产线、人员、工时
- 功能：批量修改工时
- 用于计件工资与绩效核算

## 5. 车间能耗
- 主表：期间、车间、用水（吨）、用电（KWh）、用气（m³）
- 子表：按机台明细能耗
- 用于单位产量能耗考核（电耗报表数据源）

## 6. 车间生产费用
- 字段：用水量、用水费用、用电量、用电费用、机物料、包装费用、月折旧、加工费分摊、工资、月度考核指标、折算产量、用毛率
- 流程：保存 → 提交 → 审核通过 / 驳回
- 用于生产成本分析（报表：生产成本分析-纺纱）

## 7. 车间现场问题反馈
- 列：检查人、检查日期、问题所在（区域/机台）、问题描述、整改状态
- 现场6S/巡检问题闭环管理

## 数据要点
- 现场域以"车间+期间(月)"为主数据维度
- 出勤/能耗/费用均走 提交→审核 流程状态机
- 折算出勤、折算产量、用毛率是毛纺绩效三大核心指标
