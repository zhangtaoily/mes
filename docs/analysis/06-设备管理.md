## 关系推断
保养项目/点检项目/维保方式/故障分类/配件型号 = 基础字典(带状态启用禁用) → 保养计划(车间+周期) → 生成任务 → 保养记录(执行)；点检计划 → 点检记录；故障发生 → 维保记录(关联故障分类+维修方式)；责任机台 = 人员↔机台点检责任绑定
